# 🚚 Transport Control Tower Dashboard

A comprehensive logistics operations dashboard designed to monitor route performance, SLA compliance, crew workload, and fleet capacity utilization in real-time.

## 🌟 Key Features

* **Real-time Live Data Sync:** Integrated with Google Sheets & Google Apps Script (`code.gs`) REST API for live operational updates.
* **Python Data Automation:** Consumes pre-processed batch analytics (`daily_summary.json`) generated by Python scripts (`report_processor.py`).
* **Interactive Live Maps:** Integrated with Leaflet OpenStreetMap to track route trajectories and checkpoint statuses.
* **KPI Metrics & Analytics:** Automated calculation for Net Load Rate %, SLA On-Time compliance, and Fleet Capacity efficiency.
* **Crew Matrix & Performance:** Driver & Helper scoring based on total workload, trip count, and delivery SLA.
